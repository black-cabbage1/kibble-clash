# 멍밥쟁탈전 MVP 게임 규칙

## 확정 기본값

마스터 프롬프트 안에 `2라운드·주사위 6개`와 `4라운드·주사위 8개`가 중복 기재되어 있다. 후반의 상세 규칙, 테스트 요구사항, 완료 기준이 모두 후자를 기준으로 하므로 MVP는 다음 값을 사용한다.

| 설정 | 기본값 |
|---|---:|
| 플레이어 | 사용자 1명 + AI 3명 |
| 밥그릇 | 6개 |
| 라운드 | 4 |
| 라운드 시작 주사위 | 플레이어당 8개 |
| 주사위 눈 | 1~6 |
| 밥그릇 최소 보상 | 50점 |
| 보상 카드 값 | 10, 20, 30, 40, 50 |

모든 값은 `game-config.ts`에서 변경할 수 있어야 한다.

## 경기 준비

플레이어 순서는 다음과 같다.

1. 진도믹스 — 사용자
2. 푸들 — AI
3. 퍼그 — AI
4. 골든리트리버 — AI

첫 라운드는 진도믹스부터 시작한다. 다음 라운드마다 시작 플레이어를 시계 방향으로 한 칸 이동한다.

## 라운드 준비

1. 모든 플레이어의 남은 주사위를 8개로 초기화한다.
2. 이전 라운드에 배치한 주사위를 제거한다.
3. 보상 카드 덱과 버림 더미를 준비한다.
4. Seeded RNG로 덱을 섞는다.
5. 1번부터 6번 밥그릇까지 보상 합계가 50점 이상이 될 때까지 카드를 공개한다.
6. 모든 밥그릇의 카드 목록과 총보상을 공개한 뒤 첫 턴을 시작한다.

덱이 부족하면 버림 더미를 같은 RNG로 섞어 새 뽑기 더미로 만들고 계속 배치한다. 뽑기 더미와 버림 더미가 모두 비면 전체 보상 카드 구성을 새로 복제하지 않고 명시적 오류 상태를 반환한다.

동일한 설정과 시드는 동일한 보상 배치를 만들어야 한다.

## 턴

1. 현재 플레이어의 남은 주사위를 모두 굴린다.
2. 결과를 눈별 개수로 집계한다.
3. 결과에 존재하는 눈 하나만 선택할 수 있다.
4. 선택한 눈의 주사위를 같은 번호 밥그릇에 전부 배치한다.
5. 일부만 배치할 수 없다.
6. 배치한 개수만큼 남은 주사위를 줄인다.
7. 남은 주사위가 0인 플레이어는 이후 턴에서 건너뛴다.
8. 다음으로 주사위가 남은 플레이어에게 턴을 넘긴다.
9. 모든 플레이어의 주사위가 0이면 라운드를 정산한다.

사용자는 선택 버튼으로 행동한다. AI는 현재 굴림에서 가능한 눈 중 하나만 선택해야 한다.

## AI 기본 행동

각 가능한 눈을 다음 신호로 평가한다.

- 밥그릇의 높은 보상
- 현재 배치 후 예상 생존 순위
- 자신이 동률로 상쇄될 위험
- 상대를 동률로 상쇄시키는 가치
- 이번에 배치하는 주사위 수
- 남은 주사위 수
- 다른 밥그릇에 사용할 기회비용

최고 평가 행동을 주로 선택하되 Seeded RNG 기반의 작은 오차를 적용한다. 동일한 시드에서는 AI 행동도 재현되어야 한다.

## 밥그릇 정산

밥그릇은 1번부터 6번까지 순서대로 정산한다.

### 동률 상쇄

- 주사위 수가 같은 플레이어가 둘 이상이면 해당 수에 속한 플레이어를 모두 제외한다.
- 여러 동률 집단을 각각 독립적으로 제외한다.
- 0개 배치는 경쟁 참여로 보지 않으며 동률 상쇄 대상이 아니다.

### 생존 순위

상쇄 후 남은 플레이어를 배치 주사위 수 내림차순으로 정렬한다.

### 보상

- 보상 카드를 점수 내림차순으로 정렬한다.
- 생존 1위부터 카드 한 장씩 지급한다.
- 한 플레이어는 한 밥그릇에서 최대 한 장만 받는다.
- 생존자보다 카드가 많으면 나머지는 버림 더미로 이동한다.
- 모든 참여자가 상쇄되면 아무도 받지 못하고 모든 카드를 버린다.

## 라운드 종료

- 획득 카드 점수를 플레이어의 누적 점수에 더한다.
- 상쇄된 횟수를 플레이어별로 누적한다.
- 가장 큰 단일 획득 카드 값을 기록한다.
- 모든 밥그릇의 미획득 카드를 버림 더미로 이동한다.
- 4라운드가 끝나지 않았다면 시작 플레이어를 이동하고 다음 라운드를 준비한다.

## 경기 종료

4라운드 후 누적 점수 내림차순으로 순위를 계산한다.

- 동점자는 공동 순위다.
- 타이브레이커는 없다.
- 결과에는 순위, 총점, 상쇄 횟수, 가장 큰 단일 보상을 표시한다.
- `한 판 더`는 동일 설정으로 새 시드를 사용하거나 명시적으로 전달된 시드로 새 게임을 시작한다.

## 불변 조건

- 배치된 주사위와 남은 주사위 합은 라운드 시작 수와 같다.
- 선택할 수 없는 눈은 배치할 수 없다.
- 보상은 정산 전에 변경되지 않는다.
- 한 보상 카드는 한 번만 지급되거나 버려진다.
- 게임은 사람의 입력을 기다리는 상태와 자동 진행 상태를 명확히 구분한다.
- 자동 진행에는 최대 단계 수 방어 로직을 둬 무한 루프를 감지한다.
