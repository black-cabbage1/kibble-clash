# Microsoft Store 제출 초안

## 제품

- 제품 유형: Game
- 패키지 유형: PWA → MSIX
- 제품명: 멍밥쟁탈전
- 기본 언어: 한국어(대한민국)
- 카테고리: Games
- 가격: 무료
- 대상 기기: Windows 10/11 PC
- 화면 방향: 가로

## 짧은 설명

주사위를 굴려 최고의 밥그릇을 차지하는 귀여운 강아지 보드게임

## 설명

멍밥쟁탈전은 다섯 강아지가 여섯 개의 밥그릇을 두고 경쟁하는 가벼운 주사위 보드게임입니다.

매 차례 굴린 주사위 중 하나의 숫자를 골라 같은 숫자의 주사위를 해당 밥그릇에 놓습니다. 라운드가 끝나면 밥그릇마다 가장 많은 주사위를 놓은 강아지가 사료 보상을 획득합니다. 공동 1위가 생기면 KIBBLE CLASH가 발생해 해당 강아지들은 보상에서 제외됩니다.

네 라운드 동안 가장 많은 사료 점수를 모은 강아지가 승리합니다.

## 주요 기능

- 개성이 다른 강아지 캐릭터 5종
- 한 화면에서 확인하는 밥그릇 6개와 보상
- 직관적인 주사위 선택과 배치
- 동률 상쇄 KIBBLE CLASH
- 라운드 결과와 최종 순위
- 마우스와 터치 조작 지원

## 심사 메모

- 로그인, 결제, 광고, 채팅, 사용자 제작 콘텐츠가 없습니다.
- 게임 진행 데이터는 서버로 전송하지 않습니다.
- 캐릭터 선택은 기기 로컬 저장소에만 저장됩니다.
- 네트워크 연결이 끊겨도 이전에 캐시된 앱 셸로 다시 실행할 수 있습니다.
- 설치 후 가로 방향의 전체 화면으로 실행됩니다.

## 제출 전 필요한 항목

- 공개 HTTPS PWA URL
- Microsoft Partner Center 개발자 계정
- 제품명 예약 결과
- PWABuilder로 생성한 Windows MSIX 패키지
- 192×192 및 512×512 권장 아이콘
- 게임 플레이 스크린샷 최소 1장, 권장 4장 이상
- 고객지원 연락처 또는 지원 URL
- 연령 등급 설문 답변

## 권장 스크린샷

1. 메인 화면
2. 캐릭터 선택 화면
3. 여섯 밥그릇이 보이는 게임 진행 화면
4. KIBBLE CLASH 충돌 화면
5. 최종 결과 화면
