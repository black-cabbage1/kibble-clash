# 멍밥쟁탈전 디자인 방향 업데이트

현재 게임 UI는 기능적으로는 동작하지만, 내가 원하는 방향은 더 명확하다.

## 목표 비주얼
전체 게임은 다음 느낌으로 재설계한다.

- 밝고 따뜻한 크림/베이지 톤
- 둥근 모서리와 부드러운 브라운 라인
- 모바일 캐주얼 게임 같은 친근한 화면
- 강아지 캐릭터가 화면의 주인공
- 밥그릇과 사료가 장난감처럼 귀엽게 보이는 UI
- “보드게임 관리 화면”이 아니라 “강아지 전략 게임”처럼 보일 것

## 가장 중요한 요구사항

### 1. 플레이 캐릭터 선택 화면 추가
게임 시작 전에 반드시 `플레이할 강아지 선택` 화면이 있어야 한다.

흐름:
- 홈
- 캐릭터 선택
- 선택 완료
- 게임 시작

선택 가능한 캐릭터:
- 진도믹스
- 푸들
- 퍼그
- 골든리트리버

요구사항:
- 4개의 큰 캐릭터 카드 또는 원형 아바타
- 선택된 캐릭터는 명확한 강조 표시
- 하단에 `선택 완료` 버튼
- 사용자가 선택한 강아지가 human player가 되고 나머지 3마리는 AI가 된다

### 2. 게임 플레이 화면에서 강아지 캐릭터를 복원할 것
강아지 캐릭터는 단순한 이름표가 아니라 실제 게임판의 일부처럼 보여야 한다.

반드시 반영:
- 상단 플레이어 HUD에 캐릭터 아바타 표시
- 각 밥그릇 주변에 배치된 강아지를 얼굴 토큰 또는 미니 캐릭터로 표시
- 배치 수는 `아바타 × 숫자`로 표현
- 사용자가 선택한 캐릭터가 보드에서 바로 눈에 띄게 할 것

### 3. 밥그릇은 실제 오브젝트처럼 보여야 함
- 1~6번 밥그릇이 각각 컬러풀한 밥그릇으로 보이게 한다
- 밥그릇 위/주변에 보상 카드가 보이게 한다
- 밥그릇이 단순 카드 박스가 아니라 작은 경쟁 무대처럼 보여야 한다

### 4. 전체 스타일
- 배경은 부드럽고 따뜻한 베이지 계열
- 프레임은 둥글고 두께감 있게
- 버튼은 장난감 같은 느낌
- 텍스트는 읽기 쉽고 큼직하게
- 과도한 정보표/반복 표 형태는 줄일 것

### 5. 동률 상쇄 연출
동률 상쇄는 대표 이벤트이므로 반드시 눈에 띄어야 한다.

반영:
- 충돌한 강아지 토큰 흔들림
- KIBBLE CLASH! 텍스트 오버레이
- 충돌 버스트 이펙트
- 상쇄 결과 텍스트 안내
- 살아남은 캐릭터 강조

### 6. 결과 화면
결과 화면은 표 중심이 아니라 캐릭터 중심이어야 한다.

반영:
- 우승 캐릭터를 크게 보여줄 것
- `오늘의 사료왕` 같은 감정적 보상 문구
- 총점, 충돌 횟수, 최대 보상은 보조 정보
- 버튼:
  - 한 판 더
  - 강아지 바꾸기
  - 집으로

## 주의사항
- 기존 게임 규칙은 바꾸지 않는다
- 이미지에 텍스트를 박아 넣지 않는다
- 캐릭터는 색상만으로 구분하지 않는다
- 캐릭터별 능력 차이는 없다
- UI는 모바일 가로형 기준으로 최적화한다
- 현재 대시보드형 인상을 제거하고 캐릭터 중심 게임 UI로 개선한다
