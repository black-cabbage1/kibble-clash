# 멍밥쟁탈전 이미지 리소스 제작 목록표

## 1. 제작 원칙

게임명:

- 한글명: `멍밥쟁탈전`
- 영문명: `Kibble Clash`

캐릭터:

- 진도믹스
- 푸들
- 퍼그
- 골든리트리버

화면 방향:

- 모바일 가로형
- 16:9 우선

### 중요한 제작 기준

1. **UI 문구는 이미지에 넣지 않는다.**
   - 캐릭터 이름, 점수, 버튼 문구, 보상 숫자는 Cocos UI 텍스트로 구현한다.
   - 이미지에 한글을 넣으면 오탈자, 해상도, 번역, 접근성 문제가 생긴다.

2. **캐릭터는 개별 투명 PNG로 만든다.**
   - 네 캐릭터가 한 장에 들어간 이미지는 스타일 가이드로만 사용한다.
   - 실제 게임 리소스는 캐릭터별로 따로 저장한다.

3. **그림자와 빛 효과를 이미지 바깥까지 과도하게 만들지 않는다.**
   - 잘라 쓰거나 배치할 때 여백이 지나치게 커지는 것을 방지한다.

4. **같은 캐릭터의 외형을 모든 포즈에서 일관되게 유지한다.**
   - 털색
   - 귀 모양
   - 얼굴 무늬
   - 목걸이 또는 스카프
   - 대표 색상
   - 눈과 코 비율

5. **색상만으로 캐릭터를 구분하지 않는다.**
   - 품종과 얼굴
   - 고유 소품
   - 팀 문양
   - 대표 색상
   을 함께 사용한다.

6. **스프라이트 시트는 나중에 Cocos에서 패킹한다.**
   - 생성형 이미지로 한 번에 스프라이트 시트를 만들면 프레임 간 형태가 흔들릴 수 있다.
   - 우선 개별 PNG를 제작한다.

# 4. 캐릭터 고정 설정

캐릭터 외형이 이미지마다 달라지는 것을 막기 위해 아래 설정을 모든 이미지 생성 요청에 반복 사용한다.

## 진도믹스

- 한국 진돗개 계열의 믹스견
- 황갈색과 크림색 또는 흰색 털
- 뾰족하지만 너무 날카롭지 않은 귀
- 둥글고 친근한 얼굴
- 파란색 스카프
- 대표 문양: 뼈다귀 또는 마름모
- 주인공다운 자신감과 밝은 표정

## 푸들

- 살구색 또는 크림색 곱슬털
- 둥근 얼굴과 풍성한 귀
- 분홍 리본 또는 분홍 스카프
- 대표 문양: 리본 또는 원
- 귀엽지만 계산이 빠른 전략가 표정

## 퍼그

- 베이지색 몸과 짙은 얼굴 마스크
- 주름진 얼굴과 접힌 귀
- 노란 목걸이 또는 스카프
- 대표 문양: 간식 또는 삼각형
- 욕심 많아 보이지만 미워할 수 없는 코믹한 표정

## 골든리트리버

- 밝은 황금색 털
- 부드럽게 늘어진 귀
- 초록 스카프
- 대표 문양: 발바닥 또는 사각형
- 친근하고 해맑은 표정

# 5. 공통 아트 스타일 프롬프트

아래 문장을 모든 이미지 제작 프롬프트의 앞부분에 공통으로 사용한다.

```text
멍밥쟁탈전(Kibble Clash)용 2D 캐주얼 모바일 게임 아트.
밝고 따뜻하며 가족 친화적인 분위기.
둥글고 부드러운 형태, 선명한 실루엣, 작은 모바일 화면에서도 읽히는 디자인.
귀엽고 표정이 풍부한 강아지 캐릭터.
과도하게 사실적이지 않은 고품질 2D 게임 일러스트.
동일 캐릭터의 털색, 얼굴 무늬, 귀 모양, 소품과 비율을 모든 이미지에서 일관되게 유지.
이미지 안에 글자, 숫자, 워터마크, 로고를 넣지 말 것.
게임 UI에 바로 배치할 수 있도록 피사체 전체가 잘리지 않게 중앙에 배치.
```

## 6.3 밥그릇 세트 프롬프트

밥그릇은 한 이미지에 6개를 모두 만들기보다 개별 생성 후 색상만 변경하는 방식이 안정적이다.

```text
[공통 아트 스타일]

귀여운 강아지용 사료 밥그릇 한 개.
둥글고 낮은 2D 캐주얼 게임 오브젝트.
정면보다 약간 위에서 내려다본 3/4 시점.
그릇 앞면에 흰색 발바닥 문양만 있고 글자와 숫자는 없음.
사료 보상 카드와 캐릭터 토큰을 주변에 배치하기 쉬운 단순한 실루엣.
깨끗한 가장자리, 투명 배경.
```

권장 색상:

- `bowl_1.png`: 파랑
- `bowl_2.png`: 분홍 또는 빨강
- `bowl_3.png`: 노랑
- `bowl_4.png`: 초록
- `bowl_5.png`: 보라
- `bowl_6.png`: 청록

# 8. 검수 체크리스트

각 리소스를 만든 뒤 다음을 확인한다.

## 캐릭터

- 품종이 바로 구분되는가
- 동일 캐릭터의 털색과 얼굴 무늬가 일치하는가
- 귀, 목걸이, 스카프가 일치하는가
- 작은 화면에서도 표정이 보이는가
- 이미지가 잘리지 않았는가
- 배경이 투명한가
- 글자나 워터마크가 없는가

## UI 오브젝트

- 작은 크기에서도 형태가 구분되는가
- 숫자를 UI로 올릴 공간이 있는가
- 밥그릇 번호를 UI로 올릴 공간이 있는가
- 그림자가 과도하지 않은가
- 배경이 투명한가

## 배경

- 중앙에 UI를 올릴 공간이 충분한가
- 장식이 게임 정보를 방해하지 않는가
- 16:9 화면에서 중요한 부분이 잘리지 않는가
- 텍스트가 포함되지 않았는가
