# 알려진 문제와 차단 요소

확인일: 2026-07-30

## 런타임 선택

- 현재 제품은 Cocos가 아닌 Vite 기반 Apps in Toss WebView 게임으로 구현되어 있다.
- Cocos Creator 미설치는 현재 `.ait` 빌드의 차단 요소가 아니다.
- Cocos 전환은 별도의 제품 결정이 없는 한 진행하지 않는다.

## Apps in Toss

- 앱인토스 콘솔과 로컬 설정의 `appName`은 `kibble-clash`로 일치한다.
- 표시 이름은 `멍밥쟁탈전`으로 일치한다.
- 로컬 아이콘 `/ui/kibble-clash-app-icon.png`가 `.ait` 번들에 포함된다.
- 로컬 아이콘을 포함한 `.ait` 빌드는 성공했다.
- 콘솔 QR 테스트는 수행하지 못했다.
- 공식 샌드박스는 가로 게임 테스트를 지원하지 않으므로 실제 토스앱 QR 테스트가 필요하다.

## 의존성 보안

`@apps-in-toss/web-framework@2.10.8` 설치 후:

```text
npm audit --omit=dev
low 13 / moderate 1 / high 55 / critical 1
```

- 직접 작성 코드의 취약점으로 확인된 것은 없다.
- 공식 프레임워크의 전이 의존성에서 발생한다.
- `npm audit fix --force`는 호환성을 깨뜨릴 수 있어 실행하지 않았다.
- 출시 전 공식 프레임워크 업데이트와 실제 번들 포함 여부를 다시 확인해야 한다.

## 수동 UI 검수

- 프로덕션 빌드와 HTTP 200 응답은 확인했다.
- 실제 브라우저에서 버튼을 눌러 한 판을 플레이하는 수동 검수는 아직 하지 않았다.
- 다양한 모바일 가로 화면, 글자 확대, 터치 기기, 스크린리더 검수는 남아 있다.
- 최종 아트, 사운드, 햅틱은 의도적으로 구현하지 않았다.

## 규칙 가설

- 마스터 프롬프트의 중복 규칙 중 4라운드·주사위 8개를 채택했다.
- AI 가중치와 보상 카드 장수는 재미 검증용 임시 값이다.
- 보상 카드가 고갈되면 설정된 가상 덱을 다시 섞어 재충전한다.
- 실제 플레이 후 게임 길이, 동률 빈도, 보상 편차를 조정해야 한다.
