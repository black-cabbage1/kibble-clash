# 멍밥쟁탈전 V1.5 — 튜토리얼 4/6 CLASH 설명 단순화 요청

## 작업 목적

현재 튜토리얼 4/6에서 CLASH 규칙을 설명하기 위해 아래와 같은 예시 칩이 추가되어 있다.

예:

```text
×2 ↔ ×2 CLASH · 제외
4 → 1등 · 50점
2 → 2등 · 20점
```

하지만 실제 화면에서는 이 예시가 오히려 이해를 방해한다.

사용자가 다음을 한 번에 해석해야 하기 때문이다.

- 캐릭터 아이콘이 무엇을 의미하는지
- `×2`가 무엇을 의미하는지
- 화살표와 CLASH 관계
- `4 → 1등 → 50점` 예시의 의미
- `2 → 2등 → 20점` 예시의 의미

이미 게임판 위에서 실제 CLASH 상황을 보여주고 있으므로,
설명창에서는 별도의 예시를 추가하지 않고 **핵심 규칙만 짧게 안내하는 방향으로 단순화**한다.

---

# 변경 요청

## 1. 튜토리얼 4/6의 예시 칩 제거

현재 설명 하단에 표시되는 아래 형태의 예시 UI를 모두 제거한다.

```text
×2 ↔ ×2 CLASH · 제외
4 → 1등 · 50점
2 → 2등 · 20점
```

또는 이와 유사하게 구성된 별도 예시 배지 / 칩 / 박스를 제거한다.

### 이유

- 실제 게임판에서 이미 CLASH 결과를 시각적으로 보여주고 있음
- 추가 예시가 규칙 이해보다 해석 부담을 늘림
- 작은 가로 화면에서 안내창이 불필요하게 커짐
- 튜토리얼이 다시 설명서처럼 복잡해 보일 수 있음

---

# 2. 설명은 텍스트만 남기기

튜토리얼 4/6은 아래 정도의 짧은 문구만 표시한다.

## 권장 최종 문구

```text
같은 숫자가 만나면 CLASH!
충돌한 주사위는 제외되고,
남은 주사위 중 높은 숫자부터 순위 보상을 받아요.
```

### 중요

현재 화면에 아래처럼 잘못 표현된 문구가 있다면:

```text
같은 수량이 만나면 CLASH!
```

반드시 다음으로 수정한다.

```text
같은 숫자가 만나면 CLASH!
```

CLASH 조건은 `수량`이 아니라 `같은 숫자`이다.

---

# 3. 4/6 화면 구조 단순화

최종적으로 다음 정도의 정보만 표시한다.

```text
튜토리얼 4/6

같은 숫자가 만나면 CLASH!
충돌한 주사위는 제외되고,
남은 주사위 중 높은 숫자부터 순위 보상을 받아요.

[ 다음 ]
```

별도의 예시 칩이나 추가 설명 버튼을 만들지 않는다.

---

# 4. 실제 게임판을 설명의 예시로 사용

별도의 카드 안에서 예시를 다시 만드는 대신,
현재 게임판에 이미 배치되어 있는 CLASH 상태를 그대로 활용한다.

가능하면 다음 요소는 유지한다.

- CLASH가 발생한 1번 밥그릇 강조
- 충돌한 캐릭터 / 주사위 강조
- `KIBBLE CLASH!` 또는 기존 CLASH 표시
- 배경 dim 처리
- 설명 대상 이외 UI의 시각적 약화

즉,

```text
게임판 = 실제 예시
안내창 = 핵심 규칙 설명
```

역할로 분리한다.

---

# 5. 선택 숫자 표시는 유지 가능

이전 작업에서 CLASH 이유를 명확하게 하기 위해
충돌한 캐릭터가 선택한 실제 숫자를 표시하도록 구현했다면,
해당 기능은 유지해도 된다.

예:

```text
진도믹스 6
푸들 6
```

또는 각 캐릭터 토큰 근처에 작은 `6` 배지를 표시한다.

이 숫자만으로

```text
6과 6이 만남
→ 같은 숫자
→ CLASH
```

관계를 이해할 수 있으므로,
설명창 내부의 추가 예시는 필요하지 않다.

### 주의

선택 숫자는 실제 게임 데이터와 연동하고 하드코딩하지 않는다.

---

# 6. 안내창 크기 재조정

예시 칩을 제거하면 안내창의 높이를 줄일 수 있다.

현재보다 불필요하게 큰 박스가 남지 않도록
콘텐츠 크기에 맞춰 안내 영역을 재조정한다.

단,

- `튜토리얼 4/6`은 한 줄 유지
- 본문은 자연스러운 2~3줄
- `다음` 버튼은 한 줄 유지
- 텍스트와 버튼 사이 여백은 충분히 확보

한다.

---

# 7. 기존 튜토리얼 흐름 유지

이번 수정으로 튜토리얼 단계 수를 변경하지 않는다.

현재 6단계 구조를 그대로 유지한다.

```text
1/6 게임 목표
2/6 순위별 보상
3/6 첫 번째 직접 체험
4/6 CLASH 설명
5/6 CLASH 회피 체험
6/6 결과 및 최종 전략
```

4/6의 정보만 단순화한다.

---

# 8. 게임 로직 변경 금지

이번 작업은 튜토리얼 표시 방식만 변경한다.

다음 항목은 수정하지 않는다.

- CLASH 판정 로직
- 실제 선택 숫자
- 순위 계산
- 보상 계산
- 점수
- AI
- 게임 결과
- 튜토리얼 진행 상태
