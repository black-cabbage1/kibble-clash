# 멍밥쟁탈전 V1.5 — 라운드 시작 인지성 개선 프롬프트

## 작업 목적

현재 게임 화면 상단 좌측에는 이미 현재 라운드가 `ROUND 3 / 4` 형태로 표시되고 있다.

하지만 실제 플레이 중에는 사용자의 시선이 주사위, 숫자 선택, 밥그릇, AI 행동 등에 집중되기 때문에  
게임 전체가 몇 라운드인지, 현재 어느 정도 진행되었는지 충분히 인지하지 못하는 사례가 있다.

일부 사용자는 **게임이 언제 끝나는지 모르겠어서 중간에 종료하는 경우**가 있으므로,  
라운드가 시작될 때마다 현재 진행 상황을 화면 중앙에서 명확하게 알려주는 인터미션 연출을 추가한다.

---

## 핵심 변경사항

### 1. 기존 상단 라운드 UI는 유지

현재 게임 화면 상단 좌측에 표시되는 기존 라운드 정보는 삭제하거나 위치를 변경하지 않는다.

예시:

```text
ROUND 2 / 4
```

이 표시는 실제 플레이 중에도 항상 유지한다.

이번 작업의 목적은 기존 표시를 대체하는 것이 아니라,  
**라운드 시작 시점에 진행 상황을 한 번 더 강하게 인지시키는 것**이다.

---

## 2. 라운드 시작 중앙 인터미션 추가

각 라운드 시작 직전에 게임 화면 중앙에 라운드 정보를 크게 표시한다.

### 기본 라운드

예시:

```text
ROUND
2 / 4
```

또는 기존 게임 디자인과 자연스럽다면:

```text
ROUND 2 / 4
```

한 줄 표현도 가능하다.

### 권장 우선순위

숫자 `2 / 4`가 가장 빠르게 인지될 수 있도록  
`ROUND` 텍스트보다 현재 라운드 숫자를 상대적으로 더 강조한다.

예:

```text
ROUND

2 / 4
```

- `ROUND`: 중간 크기
- `2 / 4`: 큰 크기 + Bold

---

## 3. 첫 라운드는 종료 시점까지 알려주기

첫 번째 라운드에서는 단순히 `ROUND 1 / 4`만 보여주지 말고  
게임이 총 몇 라운드로 끝나는지 사용자에게 한 번 명확하게 알려준다.

예시:

```text
ROUND 1 / 4

4라운드가 끝나면
최종 승자가 결정돼요!
```

또는 공간이 부족하면:

```text
ROUND 1 / 4

총 4라운드!
```

### 주의

- 별도의 확인 버튼은 만들지 않는다.
- 설명 팝업 형태로 만들지 않는다.
- 게임 시작 흐름을 막지 않는다.
- 최초 라운드 인터미션 안에서 자연스럽게 안내한다.

---

## 4. 마지막 라운드는 별도 연출

마지막 라운드에서는 일반적인 `ROUND 4 / 4`보다  
게임 종료가 가까워졌다는 사실을 더 명확하게 표현한다.

권장 표현:

```text
FINAL ROUND

4 / 4
```

또는

```text
FINAL ROUND
ROUND 4 / 4
```

### 목적

사용자가

> "이번 라운드가 끝나면 게임이 끝나는구나"

를 즉시 알 수 있도록 한다.

가능하면 기존 라운드 인터미션보다 약간 더 강조된 애니메이션을 사용하되,  
과도하게 화려하거나 긴 연출은 피한다.

---

# 인터미션 노출 시간

매 라운드마다 2~3초씩 게임을 멈추는 방식은 사용하지 않는다.

반복 플레이에서 템포가 느려질 수 있으므로 다음을 기준으로 한다.

### ROUND 1

약 **1.3~1.5초**

첫 라운드는 종료 조건 안내 문구가 있으므로 다른 라운드보다 조금 길게 표시할 수 있다.

### ROUND 2~마지막 이전

약 **0.9~1.2초**

### FINAL ROUND

약 **1.3~1.5초**

마지막 라운드라는 것을 충분히 인지할 수 있도록 일반 라운드보다 조금 길게 표시한다.

---

# 화면 동작

라운드 전환 흐름은 아래와 같이 변경한다.

```text
이전 라운드 종료
↓
필요한 게임 상태 초기화
↓
라운드 인터미션 등장
↓
ROUND N / TOTAL 표시
↓
약 1초 전후 유지
↓
인터미션 Fade Out
↓
주사위 버튼 활성화
↓
실제 라운드 시작
```

### 중요

인터미션이 표시되어 있는 동안에는 다음 동작이 먼저 실행되지 않도록 한다.

- 주사위 버튼 터치
- 숫자 선택
- AI 행동
- 자동 애니메이션
- 라운드 타이머가 존재한다면 타이머 진행

즉, **인터미션 종료 후 실제 라운드가 시작되어야 한다.**

---

# 애니메이션

과한 컷신처럼 만들지 않는다.

멍밥쟁탈전의 캐주얼한 분위기에 맞게 가볍고 빠르게 구현한다.

권장:

```text
Scale 0.9 → 1.05 → 1.0
Opacity 0 → 1
```

등장:

- 약 150~250ms
- 살짝 커지며 등장

유지:

- 약 600~900ms

퇴장:

- 약 150~250ms
- Fade Out

### 금지

- 화면 전체를 지나치게 번쩍이게 하는 효과
- 긴 카운트다운
- Skip 버튼
- 3초 이상 강제 대기
- 매 라운드마다 다른 복잡한 연출

---

# 배경 처리

인터미션 표시 중 기존 게임 화면은 유지한다.

다만 텍스트의 가독성을 위해 배경을 아주 약하게 어둡게 처리할 수 있다.

예:

```css
background: rgba(0, 0, 0, 0.15 ~ 0.25);
```

실제 구현 시 기존 디자인 시스템에 맞게 조정한다.

완전히 검은 화면으로 전환하거나 별도 페이지를 만들지 않는다.

---

# 터치 처리

라운드 인터미션이 표시되는 동안 사용자의 실수 터치를 막는다.

인터미션 오버레이가 게임 UI 위에 위치하여 터치를 차단하도록 한다.

단,

- 인터미션 자체를 눌러 Skip하는 기능은 추가하지 않는다.
- 1초 내외의 짧은 연출이므로 자동 종료한다.

---

# 라운드 데이터 연동

화면에 표시되는 라운드 숫자를 하드코딩하지 않는다.

현재 게임에서 사용하는 라운드 상태 값을 그대로 활용한다.

예:

```ts
currentRound
totalRounds
```

실제 프로젝트의 기존 변수명과 구조를 먼저 확인한 후 재사용한다.

표시값:

```text
ROUND {currentRound} / {totalRounds}
```

마지막 라운드 판정:

```ts
currentRound === totalRounds
```

첫 라운드 판정:

```ts
currentRound === 1
```

---

# 예외 처리

## 게임 재시작

게임을 처음부터 다시 시작하면 다시 `ROUND 1 / TOTAL` 인터미션부터 정상 노출한다.

## 화면 재렌더링

React 등의 재렌더링 때문에 동일 라운드의 인터미션이 여러 번 실행되지 않도록 한다.

한 라운드에서 **한 번만 실행**되어야 한다.

## 뒤로가기 / 게임 종료

인터미션 도중 사용자가 게임을 종료하거나 화면이 unmount되는 경우  
남아 있는 timeout / timer / animation callback을 정리한다.

메모리 누수나 다음 게임에서 인터미션이 중복 실행되는 문제가 없어야 한다.

# 반응형 / 화면 깨짐 대응

현재 앱은 다양한 모바일 화면 및 Toss Miniapp 환경에서 실행되므로  
인터미션 UI 때문에 기존 게임 화면 영역이 깨지지 않도록 한다.

특히 아래를 확인한다.

- 작은 화면
- 세로 높이가 짧은 화면
- Toss 상단 네비게이션 영역이 포함된 환경
- Safe Area가 있는 기기
- 텍스트 확대 환경
- Android / iOS

인터미션은 기존 레이아웃에 공간을 추가하는 방식이 아니라  
**게임 영역 위에 overlay 형태로 표시**하여 기존 레이아웃 크기를 변경하지 않는다.

# 접근성 고려

라운드 인터미션은 시각적 장식만으로 처리하지 않는다.

가능하다면 현재 사용 중인 접근성 구조를 확인하여  
스크린리더에서도 라운드가 바뀌었다는 정보를 인지할 수 있도록 한다.

예:

```text
2라운드, 총 4라운드
```

마지막 라운드:

```text
마지막 라운드, 총 4라운드 중 4라운드
```

단, 화면에 표시되는 모든 장식 텍스트가 중복으로 각각 읽히지 않도록 한다.

스크린리더에서는 인터미션 전체를 하나의 의미 있는 안내로 제공하는 방향을 우선한다.

# QA 체크리스트

구현 후 아래 항목을 반드시 확인한다.

- [ ] 게임 시작 시 `ROUND 1 / TOTAL` 인터미션이 정상 노출된다.
- [ ] 첫 라운드에서 총 라운드 수 또는 종료 시점 안내가 제공된다.
- [ ] ROUND 2 이후에도 각 라운드 시작마다 한 번씩 정상 노출된다.
- [ ] 같은 라운드에서 인터미션이 두 번 이상 실행되지 않는다.
- [ ] 마지막 라운드에서 `FINAL ROUND`가 표시된다.
- [ ] 인터미션 중 주사위 버튼을 누를 수 없다.
- [ ] 인터미션 중 AI 행동이 먼저 시작되지 않는다.
- [ ] 인터미션 종료 직후 정상적으로 플레이가 시작된다.
- [ ] 기존 상단 `ROUND N / TOTAL` 표시는 그대로 유지된다.
- [ ] 인터미션으로 인해 기존 게임 레이아웃 높이 또는 하단 UI가 밀리지 않는다.
- [ ] 작은 화면에서도 문구가 화면 밖으로 벗어나지 않는다.
- [ ] 게임 재시작 후 ROUND 1 인터미션이 정상적으로 다시 실행된다.
- [ ] 게임 종료 후 새 게임에서 이전 timeout/animation이 남지 않는다.
- [ ] 마지막 라운드 종료 후 기존 최종 결과 화면으로 정상 이동한다.
- [ ] 접근성 사용 시 현재 라운드를 이해할 수 있다.

# 구현 시 주의사항

이번 작업에서는 게임 규칙, 라운드 수, 점수 계산, AI 난이도, 승패 로직 등을 변경하지 않는다.

**기존 게임 로직을 최대한 유지하면서 라운드 시작 UX만 개선하는 작업으로 제한한다.**

기존 컴포넌트와 스타일 구조를 먼저 확인하고,  
불필요한 신규 상태나 중복 코드를 만들지 말고 현재 구조에 자연스럽게 통합한다.

구현 완료 후 변경한 파일 목록과 주요 변경 내용을 함께 정리해 달라.
