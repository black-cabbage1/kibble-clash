# 멍밥쟁탈전 V1.5 — 튜토리얼 UI/UX 및 게임판 정보 구조 개선 Codex 요청

## 작업 목적

현재 튜토리얼은 9단계에서 6단계로 압축되어 이전보다 흐름이 좋아졌고,
실제 게임판에서 직접 규칙을 보여주는 방향도 적절하게 반영되었다.

다만 실제 화면을 확인한 결과 다음과 같은 UI/UX 문제가 남아 있다.

이번 작업에서는 **튜토리얼 단계 수와 핵심 규칙 설명은 유지하면서**
다음 항목을 중심으로 마무리 개선한다.

1. 튜토리얼 안내 영역 확대
2. `튜토리얼 N/6` 표시 한 줄 고정
3. 버튼 텍스트 한 줄 고정
4. 순위 보상에 등수 관계를 더 명확하게 표시
5. CLASH 시 실제 선택 숫자와 충돌 관계를 더 직관적으로 표현
6. 중복 안내 문구 정리
7. 튜토리얼 완료 모달 레이아웃 개선
8. 게임판의 밥그릇별 보상 합산점수 제거

---

# 1. 튜토리얼 안내 영역 확대

현재 일부 튜토리얼 안내 영역이 지나치게 좁아
단계 표시나 버튼 텍스트가 불필요하게 여러 줄로 깨지고 있다.

예:

```text
튜토리얼 1
/6
```

또는 버튼이:

```text
결과 보
기
```

처럼 표시되는 경우가 있다.

이는 튜토리얼이 실제보다 더 복잡하고 답답하게 보이게 만든다.

## 개선 방향

튜토리얼 안내창 / tooltip의 가로 폭을 지금보다 조금 더 넓게 조정한다.

단, 게임판의 핵심 요소를 과도하게 가리지는 않도록 한다.

권장 구조:

```text
[튜토리얼 2/6]   [설명 문구]   [버튼]
```

### 원칙

- 단계 표시 영역에 최소 너비를 확보한다.
- 설명 영역에 충분한 가로 폭을 확보한다.
- 버튼 때문에 본문 폭이 지나치게 줄어들지 않도록 한다.
- 필요하면 안내창 높이를 약간 늘려도 된다.
- 전체 게임 레이아웃을 밀지 말고 overlay 방식은 유지한다.

---

# 2. `튜토리얼 N/6` 한 줄 고정

모든 단계 표시를 반드시 한 줄로 유지한다.

예:

```text
튜토리얼 1/6
튜토리얼 2/6
튜토리얼 3/6
```

### 구현 조건

- `white-space: nowrap` 또는 동일한 효과를 적용한다.
- 단계 표시 영역에 충분한 최소 너비를 지정한다.
- 단계 숫자가 두 줄로 떨어지지 않도록 한다.
- 작은 화면에서도 `튜토리얼 N/6`이 깨지지 않아야 한다.

---

# 3. 버튼 텍스트 한 줄 고정

튜토리얼 및 완료 모달의 CTA 버튼 텍스트는
가능하면 모두 한 줄로 표시한다.

현재처럼:

```text
결과 보
기
```

```text
튜토리얼
완료
```

```text
강아지 고
르고 시작
```

처럼 불필요하게 줄바꿈되지 않도록 한다.

## 권장 버튼 문구

기본 이동:

```text
다음
```

직접 체험:

```text
직접 해보기
```

결과 확인:

```text
결과 보기
```

마지막:

```text
튜토리얼 완료
```

완료 모달:

```text
강아지 선택
홈으로
```

또는 실제 흐름상 더 자연스럽다면:

```text
게임 시작
홈으로
```

### 구현 조건

- 버튼 텍스트 `nowrap`
- 버튼 최소 너비 확보
- 버튼 높이는 과도하게 커지지 않게 유지
- 긴 문구를 억지로 2줄로 넣기보다 문구 자체를 짧게 정리
- 모바일 터치 영역은 충분히 확보

# 4. 순위별 보상에 등수 관계를 더 명확하게 표시

현재 2/6 단계에서 1번 밥그릇의 보상칩을 강조하고 있지만,
신규 사용자는 여전히 다음 숫자의 의미를 한 번 더 추론해야 한다.

예:

```text
50 / 20 / 10 / 10
```

이 숫자가 각각 1등, 2등, 3등, 4등 보상이라는 점을
튜토리얼 중에는 더 명확하게 보여준다.

## 개선안

튜토리얼 2/6 단계에서만
실제 보상칩 위 또는 아래에 임시 등수 라벨을 표시한다.

예:

```text
1등   2등   3등   4등
50    20    10    10
```

### 중요

- 게임 플레이 중 항상 노출할 필요는 없다.
- 튜토리얼에서만 임시 표시한다.
- 실제 보상칩과 직접 연결된 위치에 표시한다.
- 별도의 설명 단계를 추가하지 않는다.
- 현재 6단계 구조를 유지한다.

안내 문구는 현재와 유사하게 유지한다.

권장:

```text
높은 숫자부터 준비된 순위 보상을 받아요.
꼭 1등이 아니어도 점수를 받을 수 있어요!
```

# 5. CLASH 시 실제 선택 숫자 표시

현재 CLASH 화면에서는
캐릭터 토큰 두 개와 `×2`가 표시되지만,
왜 CLASH가 발생했는지 즉시 연결하기 어렵다.

사용자가 알아야 할 핵심은:

```text
둘 다 같은 숫자 6을 선택했기 때문에 CLASH가 발생했다.
```

이다.

## 개선안

CLASH 튜토리얼 상황에서는
충돌한 캐릭터 토큰에 실제 선택 숫자를 함께 표시한다.

예:

```text
진도믹스
🎲 6

푸들
🎲 6
```

또는 작은 숫자 배지:

```text
[6]   [6]
```

### 목표

화면만 봐도:

```text
6 + 6
→ 같은 숫자
→ CLASH
```

관계가 즉시 이해되어야 한다.

### 주의

- 실제 선택 데이터와 연동한다.
- 숫자를 하드코딩하지 않는다.
- 튜토리얼 이외의 일반 게임 UI는 필요 이상으로 변경하지 않는다.

---

# 6. CLASH 이후 순위 변화는 현재 흐름 유지

현재 4/6에서 다음 내용을 한 번에 설명하는 방향은 유지한다.

```text
같은 숫자가 만나면 CLASH!
충돌한 주사위는 제외되고,
남은 주사위끼리 다시 순위를 정해요.
```

예시:

```text
6 ↔ 6 → CLASH · 제외
4 → 1등 · 50점
2 → 2등 · 20점
```

이 단계는 현재처럼 별도 추가 단계를 만들지 않고
하나의 흐름 안에서 보여준다.

가능하면 실제 게임판에서도:

1. 6 두 개 강조
2. CLASH 표시
3. 두 토큰 제거
4. 남은 주사위 강조
5. 1등 / 2등 보상 강조

순서가 자연스럽게 보이도록 한다.

# 7. 5/6과 6/6 안내 문구 중복 정리

현재 5/6 마지막과 6/6 결과 화면에서
비슷한 전략 설명이 연속으로 노출되고 있다.

예:

```text
좋아요! 높은 숫자뿐 아니라 CLASH를 피하는 것도 중요해요.
```

그리고 결과 화면에서:

```text
같은 숫자를 피하면서 더 좋은 순위의 보상을 노려보세요!
```

두 문구가 역할상 겹친다.

## 개선 방향

### 5/6 마지막

체험 완료 안내만 한다.

권장:

```text
좋아요! 이제 결과를 확인해볼까요?
```

버튼:

```text
결과 보기
```

### 6/6 결과 화면

튜토리얼 핵심 전략을 최종 정리한다.

권장:

```text
같은 숫자를 피하면서
더 좋은 순위의 보상을 노려보세요!
```

또는:

```text
높은 숫자뿐 아니라
CLASH를 피하는 것도 중요해요!
```

둘 중 하나만 사용한다.

# 8. 튜토리얼 완료 모달 레이아웃 전면 개선

현재 마지막 완료 모달은
텍스트와 버튼 영역이 너무 좁아서 줄바꿈이 심하게 발생하고 있다.

예:

```text
튜토리얼 완
료
```

```text
강아지 고
르고 시작
```

```text
홈
으
로
```

이 상태는 반드시 수정한다.

## 권장 구조

일반적인 완료 모달 구조로 단순화한다.

예:

```text
🎉 튜토리얼 완료!

준비 완료!
이제 원하는 강아지를 골라
진짜 게임을 시작해볼까요?

[ 강아지 선택 ]   [ 홈으로 ]
```

또는:

```text
🎉 튜토리얼 완료!

이제 실제 게임을 시작해볼까요?

[ 게임 시작 ]   [ 홈으로 ]
```

### 레이아웃 원칙

- `튜토리얼 완료`는 상단 제목으로 배치
- 왼쪽의 좁은 별도 컬럼 제거
- 제목 / 설명 / CTA 구조로 정리
- 버튼 텍스트는 모두 한 줄
- 버튼 사이 간격 확보
- 기본 CTA를 더 강조
- 모달의 가로 폭을 충분히 확보
- 작은 모바일 화면에서도 텍스트가 비정상적으로 줄바꿈되지 않도록 한다

# 9. 게임판의 밥그릇별 보상 합산점수 제거

현재 각 밥그릇의 순위별 보상 옆에
보상 합산점수가 추가로 표시되고 있다.

예:

```text
50 / 20 / 10 / 10   90점
```

또는:

```text
30 / 30 / 10   70점
```

이 합산점수는 제거한다.

## 제거 이유

신규 사용자는 합산점수를 보고 다음처럼 오해할 수 있다.

```text
90점이 또 하나의 보상인가?
한 명이 90점을 받는 건가?
이 밥그릇의 점수는 90점인가?
```

이번 튜토리얼의 핵심은
각 밥그릇의 보상이 **순위별로 나누어 지급된다**는 것을 명확하게 전달하는 것이다.

따라서 게임판에서는
실제로 순위별로 받을 수 있는 보상만 보여주는 것이 더 직관적이다.

## 변경 전

```text
1번 밥그릇
50 / 20 / 10 / 10 / 90점
```

## 변경 후

```text
1번 밥그릇
50 / 20 / 10 / 10
```

### 적용 범위

모든 밥그릇에서 합산점수 배지를 제거한다.

예:

- 90점
- 70점
- 60점
- 50점

등 각 순위 보상의 단순 합계로 표시되는 UI 요소를 제거한다.

### 중요

게임 로직의 보상 데이터 자체는 변경하지 않는다.

삭제 대상은 **UI에 표시되는 합산점수 정보만**이다.

---

# 10. 합산점수 제거 후 보상 영역 정렬 개선

합산점수를 제거하면 보상 영역에 여유 공간이 생긴다.

이 공간을 이용해 다음을 개선한다.

- 순위별 보상칩 간격 정돈
- 보상칩 크기 유지 또는 소폭 확대
- 밥그릇 번호와 보상칩 사이 정렬 개선
- 작은 화면에서 겹침 방지

단, 불필요하게 보상칩 전체를 크게 키우지는 않는다.

핵심은:

```text
밥그릇 번호 + 순위별 보상
```

만 빠르게 읽히는 구조다.

---

# 11. 게임 정보 역할을 명확하게 분리

게임 화면에서 각 숫자의 역할이 혼동되지 않도록 한다.

## 게임판

표시:

```text
순위별 보상
```

미표시:

```text
보상 합산점수
```

## 좌측 플레이어 영역

표시:

```text
현재까지 누적한 실제 점수
```

## 라운드 결과

표시:

```text
이번 라운드에서 실제로 획득한 점수
```

## 최종 결과

표시:

```text
최종 누적 점수 / 승패
```

각 숫자가 서로 다른 역할을 명확하게 갖도록 한다.

# 12. 현재 6단계 튜토리얼 구조 유지

이번 작업에서 다시 단계 수를 늘리지 않는다.

현재의 6단계 흐름은 유지한다.

권장 개념 구조:

```text
1/6 게임 목표
2/6 순위별 보상
3/6 직접 숫자 선택 + 배치
4/6 CLASH 및 순위 재계산
5/6 CLASH를 피하는 선택 체험
6/6 결과 확인 + 최종 전략
```

### 중요

3/6, 5/6은 하나의 체험 단계 안에서
ROLL → 숫자 선택 → 밥그릇 배치 등 여러 행동이 이어질 수 있다.

이 때문에 단계 숫자를 억지로 늘리지 않는다.

---

# 13. 모바일 / 가로 화면 대응

현재 iPhone 12 Pro 가로 기준에서 확인하고 있으나
더 작은 화면에서도 문제가 없어야 한다.

확인 대상:

- iPhone 12 Pro 가로
- 더 작은 iPhone
- Android 소형 화면
- Toss Miniapp WebView
- Safe Area가 존재하는 기기

확인 사항:

- `튜토리얼 N/6` 한 줄 유지
- 버튼 한 줄 유지
- tooltip 화면 밖 이탈 없음
- 완료 모달 버튼 줄바꿈 없음
- 보상칩 겹침 없음
- 합산점수 제거 후 정렬 정상
- tooltip이 게임판 핵심 요소를 과도하게 가리지 않음

# 14. 접근성

UI 폭을 조정하면서 접근성을 훼손하지 않는다.

특히:

- 버튼 라벨은 축약하더라도 의미가 명확해야 한다.
- 튜토리얼 단계 정보는 스크린리더에서 이해 가능해야 한다.
- `1등 / 2등 / 3등 / 4등` 라벨이 색상이나 위치에만 의존하지 않도록 한다.
- CLASH 숫자 배지는 실제 숫자 정보를 접근성 이름에도 포함한다.
- 장식 요소는 중복 낭독되지 않도록 한다.

예:

```text
1번 밥그릇.
1등 보상 50점,
2등 보상 20점,
3등 보상 10점,
4등 보상 10점.
```

CLASH:

```text
진도믹스 주사위 6.
푸들 주사위 6.
같은 숫자가 충돌하여 두 주사위가 제외됩니다.
```

# 15. 게임 로직 변경 금지

# 최종 QA 체크리스트

## 튜토리얼 레이아웃

- [ ] 모든 `튜토리얼 N/6` 표시가 한 줄이다.
- [ ] 단계 표시가 작은 화면에서도 줄바꿈되지 않는다.
- [ ] 안내 영역의 가로 폭이 충분하다.
- [ ] 설명 문구가 불필요하게 한 단어씩 줄바꿈되지 않는다.
- [ ] 안내 영역이 게임판 핵심 정보를 지나치게 가리지 않는다.

## 버튼

- [ ] `다음`이 한 줄이다.
- [ ] `직접 해보기`가 한 줄이다.
- [ ] `결과 보기`가 한 줄이다.
- [ ] `튜토리얼 완료`가 한 줄이다.
- [ ] 완료 모달 CTA가 한 줄이다.
- [ ] 버튼 텍스트를 위해 필요 시 최소 너비가 확보되어 있다.

## 순위 보상

- [ ] 튜토리얼 2/6에서 순위와 보상 관계가 명확하다.
- [ ] `1등 / 2등 / 3등 / 4등` 관계를 즉시 이해할 수 있다.
- [ ] 별도 튜토리얼 단계를 추가하지 않았다.
- [ ] 실제 보상 데이터와 표시가 일치한다.

## CLASH

- [ ] 충돌한 캐릭터가 어떤 숫자를 선택했는지 보인다.
- [ ] 같은 숫자 때문에 CLASH가 발생했다는 관계가 직관적이다.
- [ ] 숫자 데이터는 실제 선택값과 연동된다.
- [ ] CLASH 후 남은 주사위의 순위 변화가 이해된다.

## 안내 문구

- [ ] 5/6과 6/6의 전략 문구가 중복되지 않는다.
- [ ] 5/6은 결과 확인으로 자연스럽게 연결된다.
- [ ] 6/6에서 최종 전략을 한 번만 정리한다.

## 완료 모달

- [ ] 제목이 정상적인 한 줄 또는 자연스러운 구조로 표시된다.
- [ ] `튜토리얼 완료`가 세로로 깨지지 않는다.
- [ ] CTA 버튼 문구가 두세 줄로 깨지지 않는다.
- [ ] 제목 → 설명 → CTA 구조가 명확하다.
- [ ] 작은 화면에서도 모달이 정상적으로 보인다.

## 게임판 합산점수

- [ ] 모든 밥그릇에서 보상 합산점수가 제거되었다.
- [ ] `90점`, `70점`, `60점`, `50점` 등의 합계 배지가 사라졌다.
- [ ] 순위별 개별 보상은 그대로 유지된다.
- [ ] 합산점수 제거가 실제 점수 계산 로직에 영향을 주지 않는다.
- [ ] 제거 후 보상칩 정렬이 자연스럽다.
- [ ] 게임판이 이전보다 간결하게 읽힌다.

## 기존 기능 회귀

- [ ] 튜토리얼 6단계 흐름이 정상 작동한다.
- [ ] 직접 선택 체험이 정상 작동한다.
- [ ] CLASH 체험이 정상 작동한다.
- [ ] 결과 화면 이동이 정상 작동한다.
- [ ] 튜토리얼 완료 후 실제 게임 시작이 정상 작동한다.
- [ ] 튜토리얼 다시보기가 정상 작동한다.
- [ ] 일반 게임 모드에도 레이아웃 깨짐이 없다.
