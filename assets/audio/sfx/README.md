# 멍밥 쟁탈전 기본 효과음

- WAV: 44.1kHz / 16bit / Mono
- OGG: libvorbis quality 5
- 각 파일은 피크 정규화 적용

## 구성
- ui-click: 일반 버튼 클릭
- dice-roll: 주사위 굴림
- dice-land: 주사위 결과 확정
- place-dice: 밥그릇에 주사위 배치
- score-gain: 사료 점수 획득
- kibble-clash: 동률 충돌 발생
- round-complete: 라운드 종료
- victory: 최종 우승
- defeat: 우승하지 못한 결과
